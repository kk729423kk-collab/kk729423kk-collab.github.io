# Kun Long Academic Homepage

This repository contains Kun Long's static academic homepage, focused on biomedical engineering, brain-computer interfaces, embedded systems and selected engineering projects.

Website: https://kk729423kk-collab.github.io

## Local preview

The site has no build step. Open `index.html` directly, or run a local static server from the repository root:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.
